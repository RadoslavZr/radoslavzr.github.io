Privacy policy

This notice covers the IS MUNI Calendar connector operated by RadoslavZr and this information website.

Google access and its purpose

The connector requests the Google Calendar permission calendar.app.created, which allows creation of secondary calendars and management of calendars and events created by this application. This installation synchronizes only its dedicated IS MUNI calendar.

It reads calendar metadata and managed event details to compare the current calendar with confirmed source dates, avoid duplicates, preserve manual colours and reminders, and update or remove managed events.

Information stored and shared

The private server stores Google authorization tokens, the calendar identifier, event mappings, last synchronized event details and operational sync reports. Credentials remain in private server configuration, outside the public website and repository.

Google receives the selected event details: titles, course codes, dates, locations, reminders and source references or excerpts included in descriptions. Original study files are not uploaded by this Calendar connector.

Google Calendar data retrieved through this authorization is not sold, used for advertising, or used to train generalized AI models. This connector does not send retrieved Google Calendar data to AI services or Telegram. It does not request Gmail or Google Drive access.

Google API data is handled in accordance with the Google API Services User Data Policy, including its Limited Use requirements.

Retention and stopping access

Authorization credentials and sync records remain on the private server until the operator removes them; there is currently no automatic retention deadline. Copies in server backups may remain until those backups are removed.

You can revoke the application in your Google Account connections. Revocation stops further API access but does not delete existing Google Calendar events or local records. You can delete the IS MUNI calendar in Google Calendar and request removal of server credentials and sync records using the contact below.

This website

These static pages contain no analytics, tracking scripts or forms. GitHub Pages provides hosting and may retain visitor IP addresses for security purposes, as described in GitHub's privacy statement. Calendar credentials and study records are not sent to this website.
