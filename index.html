IS MUNI Calendar copies confirmed study events into a separate, private calendar in your Google account.

What it does

The connector synchronizes tests, exams, assignment deadlines, final-exam registration boundaries, and ROPOT opening and closing dates from a privately maintained study event list. Each event keeps references to its study sources.

Settings control the courses and event types included, titles, colours and reminders. Repeated synchronization updates existing events without creating duplicates. Uncertain dates wait for review.

Why Google Calendar access is needed

You authorize the connector to create a secondary calendar and manage calendars and events created by this application. This installation uses its dedicated IS MUNI calendar. It reads those entries to compare dates, preserve manual reminder and colour changes, and apply updates or cancellations.

This Calendar authorization does not request access to Gmail or Google Drive.
